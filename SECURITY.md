# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly so we can address it quickly. We take all security issues seriously.

**Preferred reporting method:**
- Email: [security@example.com](mailto:security@example.com)
- PGP key for encrypted communication (optional): [PGP key link]

Please include the following information when reporting a vulnerability:
- Detailed description of the issue
- Steps to reproduce the vulnerability
- Impact assessment (if possible)
- Any relevant screenshots or logs

Do **not** open a public issue for security vulnerabilities.
